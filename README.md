# Калькулятор

Консольный калькулятор на Python.

## Возможности

Программа поддерживает три арифметические операции:
- сложение (+);
- вычитание (-);
- умножение (*).

## Запуск

Для запуска программы выполните:

`py main.py`

После запуска необходимо ввести два числа и выбрать операцию.

## Тестирование

Для проверки работы калькулятора выполните:

`py test_operations.py`
